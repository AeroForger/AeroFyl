# Introduction

Aerofyl is a compiled systems programming language in pre-alpha. The current compiler is a temporary Rust bootstrap used to prepare the first compiler written manually in Aerofyl.

Pre-alpha uses the Rust bootstrap. Alpha 1 is planned to contain the first Aerofyl-written compiler. In a later Alpha phase, that compiler is intended to compile later versions of itself. Aerofyl is not self-hosted today.

This book introduces the currently implemented subset. The precise language reference is in the repository `spec/` directory. Bootstrap implementation details are not permanent language rules unless the specification says otherwise.
